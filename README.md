# AxiomSys

Standalone solution for the Junior Developer Assessment Part D (Sales Delivery Terms).
Architecture:
- `AxiomSysDL`: Oracle entities and EF Core mapping.
- `AxiomSysBL`: Business logic, validation, audit fields, bilingual responses.
- `AxiomSysSL`: Authenticated API controllers.
- `AxiomSysPortal`: ASP.NET Core Razor Pages UI.
